Kind: feature

- **Says what its project folder holds.** Kanban now tells other modules what it keeps in its folder (the moves on each board and which columns show), so a module that shows the project's files can name the owner.

## For agents

- `services['module.folders']` declares `.kehikot/kanban/` (not derived).
- The board re-reads on the host's own changes and on any module's step changes only; it no longer follows one module by its id.
