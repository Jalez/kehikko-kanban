- **The epic's work as a board.** Its issues, pull requests and merge requests sit in To do, In progress, In review and Done, placed from what GitHub and GitLab say. Pressing a card opens it.
- **Follows the parts you pick.** Pick parts in Kehikot's bar and the board shows only their cards.
- **Move cards on this board.** Drag a card, use its menu, or press Alt and an arrow key. A moved card says so and can be put back with one press; GitHub and GitLab are not changed.
- **Compact or comfortable, wide or narrow.** Switch how much each card shows, fold Done, and in a narrow container see one column at a time.
- **Agents can read the board.** An agent can read every column and move a card here too, marked as its move.
